# রিলস: "শৃঙ্খলা শেখাচ্ছি, নাকি অপমান করছি?"

জ্ঞানবৃত্তের জন্য ৬০ সেকেন্ডের ৯:১৬ ভার্টিক্যাল রিলস (1080×1920, 30fps)। দৃশ্যগুলো ইলাস্ট্রেশন দিয়ে আঁকা, স্ক্রিপ্টের ক্যাপশন বসানো আছে, আর সাথে একটি নিজস্ব নরম পিয়ানো মিউজিক। মিউজিক দৃশ্য ৫ থেকে আশাবাদী সুরে ওঠে।

**তৈরি ফাইল:** `out/reel.mp4`

## নিজের ছবি, লোগো ও ভয়েস যোগ করা

`assets/` ফোল্ডারে নিচের ফাইলগুলো রেখে আবার রেন্ডার করুন:

- `founder.jpg` (বা `.png`): প্রতিষ্ঠাতার ছবি। এখন দৃশ্য ৭-এ একটি প্লেসহোল্ডার সিলুয়েট আছে।
- `logo.png`: জ্ঞানবৃত্তের আসল লোগো (স্বচ্ছ ব্যাকগ্রাউন্ড হলে ভালো)। দৃশ্য ৮-এ লেখা নামের জায়গায় বসবে।
- `voice.wav` / `voice.mp3`: রেকর্ড করা ভয়েস ওভার। এটি মিউজিকের সাথে মিক্স হবে, মিউজিক তখন একটু নিচু হবে। ক্যাপশনের সময় অনুযায়ী পড়ুন (নিচে `CAPTIONS` দেখুন)।

```bash
pip install pillow numpy      # libraqm সহ Pillow লাগবে (বাংলা যুক্তাক্ষরের জন্য)
python3 make_reel.py                 # out/reel.mp4
python3 make_reel.py --no-captions   # ক্যাপশন ছাড়া: out/reel_no_captions.mp4
python3 make_reel.py --preview 4 26  # নির্দিষ্ট সেকেন্ডের স্টিল ছবি
```

ffmpeg লাগবে। ক্যাপশনের সময়গুলো `make_reel.py`-এর `CAPTIONS` তালিকায় আছে, আর মিউজিক তৈরি হয় `music.py` থেকে।
