# Miiniilove logo colourways

An exact vector copy of the reference logo, with the same shapes, heart, blobs, splash marks and wordmark, in several colour combinations. Only the colours change.

`miiniilove-colorways-sheet.png` shows all of them side by side.

## How the colours are grouped
Each colourway has four colours, placed the same way as in the reference:

| Slot | Parts |
| --- | --- |
| Dark | Wordmark "M", top-left splash |
| Main | Heart, first "i", "love" |
| Accent A | Top blob, second "i", both yellow splashes |
| Accent B | Bottom blob, "n", third "i", top-right splash |

The "M" and the shine inside the heart are cream (`#FDFAEE`).
