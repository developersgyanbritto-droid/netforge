# Miiniilove logo

Colourful logo for Miiniilove, a kids' brand for toys and clothing.

| File | Use |
| --- | --- |
| `miiniilove-logo.svg` / `.png` | Main logo: icon, name and tagline side by side |
| `miiniilove-icon.svg` / `.png` | Icon only, for app icons, social avatars, tags and labels |

All letters are outlined paths, so the SVGs look the same everywhere without needing the font installed.

## Elements
- **Icon:** a heart with teddy-bear ears and a face (toys + love).
- **Wordmark:** rounded letters (Fredoka Bold), each in a different colour, with a white sticker outline and a navy drop shadow. The dots on the four `i`s are small hearts, and the `o` in "love" is a heart.
- **Tagline:** TOYS · CLOTHING · LOVE
