# Miiniilove logo (warm palette)

A flat, warm version of the Miiniilove logo, based on the reference design and the provided colour palette.

| File | Use |
| --- | --- |
| `miiniilove-warm-stacked.svg` / `.png` | Main logo: heart icon above the name and tagline |
| `miiniilove-warm-logo.svg` / `.png` | Horizontal logo: icon and name side by side |
| `miiniilove-warm-icon.svg` / `.png` | Icon only, for social avatars, app icons, tags and labels |

The SVGs have a transparent background. The PNG previews are shown on a light cream background (`#FDF8EF`). All letters are outlined paths, so no font is needed.

## Elements
- **Icon:** an orange heart with a white rounded "M" and a white shine, layered over a yellow blob and a teal blob, with small splash lines on each side.
- **Wordmark:** "Miiniilove" in flat, rounded letters (Fredoka Bold). The dots on the four `i`s are small hearts, and the `o` has a heart-shaped hole.
- **Tagline:** TOYS · CLOTHING

## Palette
| Colour | Hex | Used for |
| --- | --- | --- |
| Light brown | `#E8CCAD` | Backgrounds, packaging, cards |
| Orange | `#EC802B` | Heart, "love", accents |
| Yellow | `#EDC55B` | Blob, letters, splash lines |
| Teal | `#66BCB4` | Blob, letters, splash lines |
| Deep brown (added) | `#A85A2A` | The "M" in the wordmark and the tagline |

The light brown is too pale for text, so a deeper shade of it was added for the "M" and the tagline.
